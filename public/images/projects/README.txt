[나윤진 포트폴리오] 프로젝트 이미지 등록 및 교체 가이드
===================================================================

안녕하세요, 나윤진 님!
이 폴더는 포트폴리오 웹사이트의 'Project' 섹션에 표시될 실제 이미지 파일들을 보관하는 공간입니다.

현재는 실제 이미지가 없더라도 웹 화면에서 깔끔한 플레이스홀더(Placeholder)와 
해당 위치에 필요한 파일명이 자동으로 안내되고 있습니다.

추후 실제 프로젝트 이미지(PPT 캡처본 등)를 등록하시려면 아래 파일명 그대로
이 폴더(public/images/projects/) 안에 복사해서 넣어주시면 됩니다.
별도의 코드 수정 없이 웹 화면에 즉시 실제 이미지로 자동 전환됩니다!

3. 3번 프로젝트 이미지 : project_03.png

   새 프로젝트 항목을 추가하시고 해당 파일명(예: project_06.png)을 넣어주시면 
   개수에 맞춰 자동으로 화면에 동적 반영됩니다.
